# Конструктор заготовки: захисний ковпак мотора квадрокоптера

**Автор:** ст. викл. С. В. Носко — приклад для ШІ-напряму КМІТ
**Напрями:** 1. Застосунки · 5. Інженерний ШІ
**Посилання:** https://kmit-khpi.github.io/blank-calculator/

## Що це

Навчальний калькулятор для холодного витягування циліндричного стакана без фланця з алюмінієвого листа. Задаєте зовнішній діаметр, висоту й товщину — отримуєте діаметр плоскої заготовки, коефіцієнт витягування, площу й масу заготовки, 3D-модель і креслення.

Формули (спрощений навчальний розрахунок, рівність площ поверхонь):
- d = dз − s
- D₀ = √(d² + 4·d·h)
- m = d / D₀
- A = π·D₀²/4, маса = A·s·0,0027 г (алюміній)

Перевірка: dз = 28, h = 12, s = 0,5 → D₀ = 45,6 мм, m = 0,60, маса ≈ 2,20 г.

## Як зроблено
