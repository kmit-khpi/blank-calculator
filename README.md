### Як оновити проєкт

1. Завантажте з Google AI Studio архів (кнопка **Download**) і розпакуйте його.
2. На цій сторінці: **Add file → Upload files** і перетягніть **вміст** розпакованої папки.
3. **Не завантажуйте** файли `.env`, `.env.local` та папку `node_modules`.
4. Натисніть **Commit changes**. За 1–3 хвилини сайт оновиться за посиланням вище.

Перевірити, чи пройшла публікація: вкладка **Actions** — зелена позначка ✓ означає успіх, червоний ✗ — помилку (напишіть у Telegram-групу).

> Застосунки, які самі звертаються до Gemini, на GitHub Pages працюватимуть без ШІ-частини: API-ключ у відкритий код не викладаємо. Такими застосунками діліться через кнопку **Share** в AI Studio.
